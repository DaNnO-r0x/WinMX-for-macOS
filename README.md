## About

**WinMX for macOS** is an independent, unofficial project inspired by the classic WinMX experience, bringing its familiar look and community spirit to Mac.

## Project goals

- A classic WinMX-inspired interface
- WPN and OpenNap network compatibility
- Chat rooms with legacy color formatting
- Customizable nicknames and preferences
- Chat hosting from within the app
- File-sharing capabilities

> **Development status:** v1.0.0 is an early release. These are project goals; some features may be unfinished, experimental, or unavailable.

## Installation

1. Download the DMG from the link above.
2. Open the downloaded disk image.
3. Copy the application to the **Applications** folder.
4. Launch the application.

If macOS displays a security warning, verify the file and its source before deciding whether to open it.
